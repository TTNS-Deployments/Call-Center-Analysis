# Support

## Raising a support ticket

1. Sign in to the DBCH portal at https://dobigcloudhub.ttns.in with the user ID and password sent to you from hello@ttns.in.
2. Open **Support** in the left menu, then **View Ticket**.
3. Click **+** to raise a new ticket and complete all mandatory fields.
4. Click **Submit** and keep the generated **Ticket ID** for reference.

Managed infrastructure support is provided 24x7 as defined in the support matrix of the Statement of Work.

## Before you raise a ticket

- **Pipeline issues:** open the web app **Pipeline** page. Failed calls show the stage and the error message, and can be retried there. Function logs are in Application Insights (`<prefix>-<env>-*-appi`).
- **Sign-in issues:** check that the user is assigned a role on the enterprise application *Call Center Analysis (<env>)*.
- **Deployment issues:** see the troubleshooting section in [Documents/deployment-guide.md](Documents/deployment-guide.md#troubleshooting).

Include the call ID, environment, approximate time (with time zone) and any error text in the ticket.
